## Restaurant POS System

>A modern Restaurant Point of Sale (POS) system designed to simplify restaurant operations with a clean user experience, fast performance, and scalable architecture.

## 🛠️ Technology Stack

The system is built using a modern full-stack JavaScript/TypeScript architecture designed for scalability, maintainability, and performance.

---

### 🎨 Frontend

* **HTML5** – Structure of the web application
* **React** – UI library for building interactive user interfaces (Single Page Application)
* **TypeScript** – Static type checking for safer and more maintainable code
* **Tailwind CSS** – Utility-first CSS framework for fast and consistent UI styling

---

### ⚙️ Backend

* **Node.js** – JavaScript runtime environment for server-side development
* **NestJS** – Progressive Node.js framework for building scalable and modular backend applications
* **TypeScript** – Used across the backend for type safety and better code structure

---

### 🗄️ Database

* **PostgreSQL** – Relational database system used to store and manage all system data such as orders, users, inventory, and transactions

---

### 🔌 API Architecture

* **RESTful API** – Used for communication between frontend and backend
* **JSON** – Standard data format for API communication

---

### 🧰 Development Tools

* **Git** – Version control system
* **GitHub** – Source code management and collaboration
* **Postman** – API testing and debugging tool
* **Visual Studio Code** – Primary code editor

---

### 🧠 Key Design Principles

* Component-Based Architecture (Frontend)
* Modular Architecture (Backend - NestJS)
* Separation of Concerns (Frontend / Backend / Database separation)
* Scalable and Maintainable System Design
